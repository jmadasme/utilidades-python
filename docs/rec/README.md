# rec/ — video explicativo

Este directorio contiene el video asciinema de **Utilidades Python: dictado local, cuatro niveles** y el reproductor
que se usa en la página del proyecto.

- `utilidades-python.cast`: grabación original (asciicast v2).
- `utilidades-python.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:52. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
